<Warning>
  All admin endpoints require ADMIN role. Unauthorized requests will return 403 Forbidden.
</Warning>

## List All Users

Retrieve a paginated list of all users with admin-level details.

<CodeGroup>
```bash cURL
curl -X GET 'https://api.sportshub.com/api/admin/users?page=0&size=20' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'
```

```javascript JavaScript
const response = await fetch('https://api.sportshub.com/api/admin/users?page=0&size=20', {
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN'
  }
});
const users = await response.json();
```
</CodeGroup>

### Query Parameters

<ParamField query="page" type="integer" default="0">
  Page number for pagination (0-indexed)
</ParamField>

<ParamField query="size" type="integer" default="20">
  Number of users per page
</ParamField>

### Response

<ResponseField name="id" type="UUID">
  Unique user identifier
</ResponseField>

<ResponseField name="email" type="string">
  User's email address
</ResponseField>

<ResponseField name="emailVerified" type="boolean">
  Whether the email has been verified
</ResponseField>

<ResponseField name="displayName" type="string">
  User's display name
</ResponseField>

<ResponseField name="phoneNumber" type="string">
  User's phone number
</ResponseField>

<ResponseField name="avatarUrl" type="string">
  URL to user's avatar image
</ResponseField>

<ResponseField name="role" type="string">
  User role: `ADMIN`, `OWNER`, or `PLAYER`
</ResponseField>

<ResponseField name="ownerRequestStatus" type="string">
  Owner request status: `PENDING`, `APPROVED`, or `REJECTED`
</ResponseField>

<ResponseField name="active" type="boolean">
  Whether the user account is active
</ResponseField>

<ResponseField name="lastLoginAt" type="timestamp">
  Last login timestamp
</ResponseField>

<ResponseField name="createdAt" type="timestamp">
  Account creation timestamp
</ResponseField>

## Get Pending Owner Requests

Retrieve users who have requested owner role approval.

<CodeGroup>
```bash cURL
curl -X GET 'https://api.sportshub.com/api/admin/users/pending-owners' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'
```
</CodeGroup>

### Response

Returns an array of `UserProfileResponse` objects with pending owner requests.

## Change User Role

Manually change a user's role in the system.

<CodeGroup>
```bash cURL
curl -X PATCH 'https://api.sportshub.com/api/admin/users/{userId}/role' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "role": "OWNER"
  }'
```

```javascript JavaScript
const response = await fetch(`https://api.sportshub.com/api/admin/users/${userId}/role`, {
  method: 'PATCH',
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    role: 'OWNER'
  })
});
```
</CodeGroup>

### Path Parameters

<ParamField path="userId" type="UUID" required>
  The unique identifier of the user
</ParamField>

### Request Body

<ParamField body="role" type="string" required>
  New role for the user. Allowed values: `ADMIN`, `OWNER`, `PLAYER`
</ParamField>

### Response

Returns `204 No Content` on success.

## Toggle User Active Status

Activate or deactivate a user account.

<CodeGroup>
```bash cURL
curl -X PATCH 'https://api.sportshub.com/api/admin/users/{userId}/toggle-active' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'
```
</CodeGroup>

### Path Parameters

<ParamField path="userId" type="UUID" required>
  The unique identifier of the user
</ParamField>

### Response

Returns `204 No Content` on success. The user's active status will be toggled (active becomes inactive, inactive becomes active).
